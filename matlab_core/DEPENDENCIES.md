# MATLAB runtime dependency closure

MATLAB `matlab.codetools.requiredFilesAndProducts` was run on
`run_focus_core.m` after an independent real simulation. It reported exactly
the 14 files below and the base product `MATLAB 24.2`; no additional toolbox
was reported.

## Main call chain

```text
run_focus_core
  -> focusing_library_config
       -> configure_paper_focusing_regions
  -> build_multiuser_model
       -> tma_frequency_plan
       -> build_array_geometry
            -> resolve_array_configuration
       -> synthesize_near_field_weights
            -> array_element_gain
  -> compute_harmonic_weight_maps
       -> resolve_focusing_regions
            -> tma_frequency_plan
       -> compute_harmonic_weight_field
            -> build_harmonic_weight_operator
                 -> array_element_gain
  -> measure_focal_spots
  -> compute_harmonic_weight_field (exact requested-point power)
  -> return result
```

The external chain is:

```text
config.json
  -> agent_run_simulation
  -> run_focus_core
  -> result.json
```

## MAT files

No MAT file is a runtime dependency of the selected path, so none was copied
into `matlab_core`.

`runs/original_baseline.mat` is a small audit artifact generated by executing
the source functions at three targets. It is used only by
`tests/test_consistency.m`; neither `run_focus_core` nor the JSON interface
loads it.
